## 投資大師選股策略-投資策略

| 類型      | 代表                             | 核心策略                 | 關鍵指標                                           |
| :------ | :----------------------------- | :------------------- | :--------------------------------------------- |
| 動能投資    | 墨菲、米尼維尼、達華斯、李佛摩                | 順勢交易、嚴格停損            | 價格動能、成交量、箱型突破                                  |
| 價值      | 巴菲特、蒙格、卡拉曼、格拉罕、奈夫              | 安全邊際、低估值             | PE、PB、護城河                                      |
| 成長      | 林區、費雪、歐尼爾、伍德                   | 顛覆式創新、成長股            | GPEG、ROIC、營收成長                                 |
| 反向      | 科斯托蘭尼、伯里、伊坎、索羅斯                | 逆向投資、反身性             | 市場心理、總經                                        |
| 量化      | 西蒙斯、葛林布雷、達里歐                   | 模型、全天候               | 數學公式、資產配置                                      |
| 多因子投資模型 | 尤金·法馬、肯尼斯·法蘭許、詹姆斯·西蒙斯、克里夫·艾斯尼斯 | 追蹤多個驅動因子(如價值、動能、品質等) | 因子得分(Factor Score)與資訊比率(Information Ratio, IR) |
動能投資（Momentum Investing）是近 40 年金融學研究中，最具實證支援的因子（Factor）之一，與價值（Value）、品質（Quality）、低波動（Low Volatility）、規模（Size）並列五大因子。

它的核心理念只有一句話：

> **漲得最強的股票，未來一段時間通常還會繼續強；跌得最弱的股票，也容易持續弱勢。**

## 選股方法論（四大流派實作骨架）

> 詳細 15 種量化條件見 [[15種常見投資策略完整指南quant-trading-strategies-guide|15 種常見投資策略完整指南quant-trading-strategies-guide]]；每日推薦實作見 [[每日15檔選股推薦系統設計規格daily-stock-picker-spec|每日 15 檔選股推薦系統設計規格daily-stock-picker-spec]]。

| 流派      | 進場邏輯                                      | 出場/停損                | 適用標的        |
| ------- | ----------------------------------------- | -------------------- | ----------- |
| **動能**  | 多頭排列（MA5>MA20>MA60）+ 近 60 日報酬前 10% + 量能放大 | 跌破 MA20 或最大回撤 >8% 出場 | 強勢產業龍頭      |
| **價值**  | PE<12、PB<1.5、殖利率>5%、ROE>15%               | 本益比回歸均值或護城河破壞        | 金融/傳產/收益型   |
| **成長**  | 營收 YoY>20%、ROIC>15%、GPEG<1                | 成長率連兩季衰減即減碼          | 半導體/AI/新興產業 |
| **多因子** | 價值+動能+品質+低波動 加權評分，取前 10                   | 因子反轉（如動能轉負）再平衡       | 前 300 大市值輪動 |

**核心原則**：
1. 先定流派 → 再選因子 → 最後排程執行（不混用互斥邏輯）
2. 每筆交易預設停損，異常率 >30% 的資料來源「拒絕寫入」（見量化交易鐵律）
3. 策略需回測 Sharpe > 0.8 才上線

## Agent 可執行選股流程

```text
1. 範圍：DB 前 300 大市值台股（每日更新）
2. 因子計算：PE/PB/殖利率/ROE + 動能(60日報酬/MA排列) + 技術(RSI/MACD)
3. 評分：多因子加權 → 總分排名
4. 分桶：短期(5) / 中期(5) / 長期(5) 各取前 5
5. 驗證：yfinance 交叉比對股數/收盤價，異常不放行
6. 推送：Telegram 14:15 發送（cron: cf916e0efd42）
```

實作入口：`quant-trading` skill → `daily_stock_pick.py`

## 簡潔提示詞（供 Agent 直接使用）

**A. 每日選股推薦**
```text
執行每日台股選股：從 DB 前 300 大市值，用多因子評分（PE/PB/殖利率/ROE + 動能 + 技術），

```

**B. 特定流派選股**
```text
用「動能流派」選股：MA5>MA20>MA60 多頭排列 + 近60日報酬前10% + 量能放大，
前 300 大市值中選 10 檔，標註進場/停損條件。
```

**C. 策略回測驗證**
```text
對 [策略名] 做回測：前 300 大市值、2024-01 至今、初始 100 萬，
計算 Sharpe/最大回撤，Sharpe<0.8 不建議上線。
```

**D. 單股深度分析**
```text
分析 [股票代號]：技術面(均線/MACD/RSI) + 基本面(PE/PB/ROE/殖利率) +
籌碼面，給出多/空結論與關鍵價位。
```
