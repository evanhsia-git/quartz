# Quantitative Trading Strategies — 15 種常見投資策略完整指南

## 概論（Overview）

**量化交易**是將投資決策轉為明確、可重複、可回測的規則，交由程式（或 AI Agent）自動篩選標的，去除人為情緒與盤感偏誤。本指南把 15 種常見策略分為 5 大類，每種策略均附「核心邏輯 / 參數 / 選股條件 / **AGENT 提示詞**」，並額外提供 **20+ 技術指標**、**15 種基本面因子**、**AI Agent 提示詞資料庫**、**多因子評分系統**、**風險管理**、**回測框架** 與 **績效分析** 等完整工具鏈，可直接套用於 DB 前 300 大市值股票的每日選股。

## 一、趨勢動量類（Trend & Momentum）

### 1. 均線交叉（Moving Average Crossover）

**核心邏輯**：短均線上穿長均線買進，下穿賣出

| 參數 | 常見組合 | 說明 |
|------|---------|------|
| 短/長 | 5/20 | 短期交易，敏感度高 |
| 短/長 | 20/60 | 中期波段，訊號穩定 |
| 短/長 | 60/120 | 長期趨勢，假訊號少 |

**選股條件**：今日收盤價 > MA5 > MA20 > MA60（多頭排列）

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 均線計算 | `daily_prices_YYYYMMDD` | 近 60 日 `close` |
| 篩選 | 計算值 | `close > MA5 > MA20 > MA60` |
| 排序 | 計算值 | 依 (close-MA20)/MA20 乖離率降冪 |

```
從 daily_prices_YYYYMMDD 取前300大近60日 close，計算 MA5/MA20/MA60，
篩出多頭排列(close>MA5>MA20>MA60)，依 MA20 乖離率排序，輸出前10檔：代號/名稱/收盤/MA5/MA20/MA60
```

### 2. 動量策略（Momentum）

**核心邏輯**：過去 N 天報酬率排名前 10% 做多

| 回看期 | 持倉期 | 說明 |
|--------|--------|------|
| 60 天 | 20 天 | 中期動量，最常見 |
| 20 天 | 5 天 | 短期動能，交易頻率高 |
| 252 天 | 20 天 | 長期反轉前的動量延續 |

**選股條件**：`過去 60 天報酬率排名前 10%`（前 30 名）

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 報酬率 | `daily_prices_YYYYMMDD` | (今日close/60日前close)-1 |
| 篩選 | 計算值 | 報酬率排名前 10% |
| 排序 | 計算值 | 60 日報酬率降冪 |

```
從 daily_prices_YYYYMMDD 取前300大，計算(今日close/60交易日前close-1)為60天報酬率，
排序取前10檔（排名前10%），輸出：代號/名稱/60D報酬率/現價
```

### 3. 通道突破（Donchian Channel / 海龜交易法）

**核心邏輯**：突破近 N 天高點買進，跌破低點賣出

| 參數 | 說明 |
|------|------|
| 20 日通道 | 短線突破，海龜經典 |
| 55 日通道 | 中線波段，過濾假突破 |

**選股條件**：`收盤價 = 近 20 日最高價`

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 通道上緣 | `daily_prices_YYYYMMDD` | 近 20 日 `high` 最大值 |
| 突破判斷 | 計算值 | 今日 `close >= 近20日最高` |
| 排序 | `daily_prices` | 成交量放大者優先 |

```
從 daily_prices_YYYYMMDD 取前300大近20日 high，找今日 close 突破(>=)近20日最高價者，
依成交量降冪排序，輸出前10檔：代號/名稱/現價/20日高點/量能
```

### 4. MACD 策略

**核心邏輯**：MACD 線上穿 Signal 買進，下穿賣出

**選股條件**：`MACD 柱 > 0 且 MACD 線向上`

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| DIF/DEA | `daily_prices_YYYYMMDD` | close 算 EMA12/EMA26/DEA9 |
| 篩選 | 計算值 | MACD 柱>0 且 DIF 今日>昨日 |
| 排序 | 計算值 | MACD 柱值降冪 |

```
從 daily_prices_YYYYMMDD 取前300大 close，計算 DIF=EMA12-EMA26、DEA=DIF的EMA9、
柱=(DIF-DEA)*2，篩出柱>0且DIF向上者，依柱值排序輸出前10檔：代號/名稱/DIF/DEA/柱
```

## 二、均值回歸類（Mean Reversion）

### 5. 布林帶回歸（Bollinger Bands）

**核心邏輯**：價格觸及下軌買進，觸及上軌賣出

| 參數 | 說明 |
|------|------|
| 20 日 ± 2σ | 標準布林帶 |
| 觸下軌 + RSI < 30 | 雙重確認，勝率更高 |

**選股條件**：`收盤價 < 布林下軌`

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 中軌/標準差 | `daily_prices_YYYYMMDD` | 近 20 日 close 均值與 σ |
| 下軌 | 計算值 | 下軌 = MA20 - 2σ |
| 篩選 | 計算值 | 今日 `close < 下軌` |

```
從 daily_prices_YYYYMMDD 取前300大近20日 close，計算 MA20 與標準差σ，
下軌=MA20-2σ，篩出今日 close<下軌者，依 (下軌-close)/close 幅度排序輸出前10檔
```

### 6. RSI 超買超賣

**核心邏輯**：RSI < 30 超賣買進，RSI > 70 超買賣出

| RSI 週期 | 說明 |
|----------|------|
| RSI(14) | 標準參數 |
| RSI(9) | 敏感度更高 |

**選股條件**：`RSI(14) < 35`（超賣區）

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 漲跌幅 | `daily_prices_YYYYMMDD` | 近 15 日 close 日變動 |
| RSI | 計算值 | 14 日平均漲幅/(平均漲+跌) |
| 篩選 | 計算值 | `RSI(14) < 35` |

```
從 daily_prices_YYYYMMDD 取前300大近15日 close，計算 RSI(14)=100-100/(1+平均漲幅/平均跌幅)，
篩出 RSI<35（超賣）者，依 RSI 升冪排序輸出前10檔：代號/名稱/RSI/現價
```

### 7. 配對交易（Pairs Trading）

**核心邏輯**：找兩檔高度相關股票，價差偏離時做多弱勢 / 放空強勢

**適合產業配對**：
- 台積電 (2330) vs 聯電 (2303)
- 富邦金 (2881) vs 國泰金 (2882)
- 台塑 (1301) vs 南亞 (1303)

**選股條件**：`價差 Z-score > 2 時放空強勢股 + 買進弱勢股`

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 價差序列 | `daily_prices_YYYYMMDD` | 兩檔近 60 日 close 比值 |
| Z-score | 計算值 | (今日價差-均值)/標準差 |
| 訊號 | 計算值 | `\|Z\| > 2` 觸發配對 |

```
給定配對(如2330,2303)，從 daily_prices_YYYYMMDD 取近60日 close，
計算價差比=A/B，Z=(今日價差-均值)/σ；當 Z>2 放空A買B、Z<-2 反向，輸出配對/Z值/建議方向
```

## 三、因子投資類（Factor Investing）

### 8. 價值因子（Value Factor）

**核心邏輯**：低 PE、低 PB、高殖利率的股票長期有超額報酬

| 因子 | 條件 | 說明 |
|------|------|------|
| 低 PE | PE < 12 且 PE > 0 | 排除虧損股 |
| 低 PB | PB < 1.5 | 股價被低估 |
| 高殖利率 | DY > 5% | 穩定配息 |

**選股條件**：`PE < 12 AND PB < 1.5 AND DY > 5%`

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 估值 | `daily_prices` | `pe_ratio` / `pb_ratio` / `dividend_yield` |
| 篩選 | 計算值 | pe∈(0,12) 且 pb<1.5 且 dy>5% |
| 排序 | 計算值 | 三項排名百分位平均 |

```
從 daily_prices 取前300大 pe_ratio/pb_ratio/dividend_yield（排除三項全NULL的ETF），
篩出 pe_ratio介於0~12 且 pb_ratio<1.5 且 dividend_yield>5%，依綜合估值排名輸出前10檔
```

### 9. 品質因子（Quality Factor）

**核心邏輯**：高 ROE、低負債、穩定獲利的公司長期勝出

| 因子 | 條件 |
|------|------|
| 高 ROE | ROE > 15% |
| 低負債 | 負債比 < 40% |
| 穩定 EPS | 近 4 季 EPS 皆為正 |

**選股條件**：`ROE > 15% AND 負債比 < 40%`

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 品質指標 | `stock_overview` | `roe` / `debt_ratio` |
| 篩選 | 計算值 | `roe > 15` 且 `debt_ratio < 40` |
| 排序 | 計算值 | ROE 排名% + (100-負債比排名%) |

```
從 stock_overview 取前300大 roe/debt_ratio，篩出 roe>15 且 debt_ratio<40，
依 ROE 降冪、負債比升冪綜合排序，輸出前10檔：代號/名稱/ROE/負債比
```

### 10. 規模因子（Size Factor）

**核心邏輯**：小市值股票長期有溢價（前 300 大較不適用）

**替代應用**：在前 300 大中選「相對小市值」的 50 檔

**選股條件**：`market_cap 在前 300 大中排名後段（201~300 名）`

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 市值 | `stock_overview` | `market_cap` |
| 篩選 | 計算值 | 前 300 大中市值最小的 50 檔 |
| 排序 | `stock_overview` | `market_cap` 升冪 |

```
從 stock_overview 取市值前300大，依 market_cap 升冪排序取最小的50檔（相對小市值），
再結合動量或品質過濾，輸出：代號/名稱/市值/排名
```

### 11. 低波動因子（Low Volatility）

**核心邏輯**：低波動股票風險調整後報酬更佳

**選股條件**：`20 日年化波動率 < 25%`

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 日報酬 | `daily_prices_YYYYMMDD` | 近 20 日 close 日變動 |
| 年化波動 | 計算值 | 日報酬 σ × √252 |
| 篩選 | 計算值 | 年化波動率 < 25% |

```
從 daily_prices_YYYYMMDD 取前300大近20日 close，計算日報酬標準差×√252 為年化波動率，
篩出<25%者，依波動率升冪排序輸出前10檔：代號/名稱/年化波動率
```

## 四、事件驅動類（Event-Driven）

### 12. 財報事件（Post-Earnings Announcement Drift）

**核心邏輯**：財報優於預期後，價格會持續漂移上漲

**選股條件**：`最新財報 EPS > 市場共識 × 1.1`

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 財報 | `stock_overview` | 最新季 `eps` / 年增率 |
| 事件後表現 | `daily_prices_YYYYMMDD` | 財報後 close 漂移 |
| 篩選 | 計算值 | EPS 優於前期 + 股價未反應 |

```
從 stock_overview 取最新季 eps 與去年同季比較，篩出 EPS 年增>10% 且近5日漲幅<5%（尚未反應）者，
結合 daily_prices 成交量放大，輸出前10檔：代號/名稱/EPS/年增率/近5日漲幅
```

### 13. 除權息策略

**核心邏輯**：除權息前買進，賺取股息 + 填息行情

**選股條件**：
- 殖利率 > 4%
- 近 3 年填息率 > 70%
- 除權息日在 30 天內

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 殖利率 | `daily_prices` | `dividend_yield > 4` |
| 除權息日 | `stock_overview` | 除息日在未來 30 天內 |
| 填息率 | 歷史資料 | 近 3 年填息率 > 70% |

```
從 daily_prices 篩 dividend_yield>4，結合 stock_overview 除權息日在未來30天內、
近3年填息率>70%，依殖利率×填息率排序輸出前10檔：代號/名稱/殖利率/除息日/填息率
```

## 五、多因子複合 + 風險管理

### 14. 多因子選股（Multi-Factor Scoring）⭐ 推薦

**核心邏輯**：結合 Value + Momentum + Quality 打分排名

**評分公式**：
```
總分 = 價值分數 × 0.4 + 動量分數 × 0.3 + 品質分數 × 0.3

價值分數 = (PE 排名% + PB 排名% + DY 排名%) / 3
動量分數 = 60 天報酬率排名%
品質分數 = (ROE 排名% + (100 - 負債比排名%)) / 2
```

**選股條件**：`總分排名前 10 名`

**🤖 AGENT 提示詞**

| 因子 | 資料表 | 欄位 | 權重 |
|------|--------|------|------|
| 價值 | `daily_prices` | pe/pb/dividend_yield | 0.4 |
| 動量 | `daily_prices_YYYYMMDD` | 60 日報酬率 | 0.3 |
| 品質 | `stock_overview` | roe/debt_ratio | 0.3 |

```
對前300大（排除ETF）分別計算：價值分(pe/pb/dividend_yield排名%平均)、
動量分(60天報酬率排名%)、品質分((roe排名%+(100-負債比排名%))/2)；
總分=價值×0.4+動量×0.3+品質×0.3，取前10名輸出：代號/名稱/總分/各因子分
```

### 15. 風險平價（Risk Parity）

**核心邏輯**：依波動率分配權重，而非資金等權重

**權重公式**：
```
權重_i = (1 / 波動率_i) / Σ(1 / 波動率_j)
```

**🤖 AGENT 提示詞**

| 用途 | 資料表 | 欄位/條件 |
|------|--------|----------|
| 波動率 | `daily_prices_YYYYMMDD` | 各檔近 20 日年化波動率 |
| 反比權重 | 計算值 | (1/σ_i) / Σ(1/σ_j) |
| 輸出 | 計算值 | 每檔建議配置權重% |

```
對選股清單各檔，從 daily_prices_YYYYMMDD 算近20日年化波動率σ，
權重_i=(1/σ_i)/所有(1/σ)總和，正規化為百分比，輸出：代號/名稱/波動率/建議權重%
```

## 七、多因子評分系統（Scoring Engine）

### 評分流程

```
1. 取樣：前300大、排除ETF
2. 取因子：技術(動量/波動) + 基本面(價值/品質/成長)
3. 標準化：各因子 → 排名百分位(0~100)；優選方向為低者取 100-排名%
4. 加權：分數 = Σ(因子百分位 × 權重)
5. 排序：總分降冪，取前 N
6. 配權：風險平價 or 等權
```

### 預設權重配置（可依風格調整）

| 因子群 | 代表因子 | 穩健型 | 積極型 | 價值型 |
|--------|---------|-------|-------|-------|
| 價值 | PE/PB/DY | 0.30 | 0.15 | 0.50 |
| 品質 | ROE/負債比 | 0.30 | 0.20 | 0.25 |
| 動量 | 60D報酬 | 0.20 | 0.45 | 0.10 |
| 成長 | EPS/營收YoY | 0.15 | 0.15 | 0.10 |
| 低波動 | 年化σ | 0.05 | 0.05 | 0.05 |

### 評分公式

```
Score = 0.4×Value% + 0.3×Momentum% + 0.3×Quality%   （預設）
Value%    = mean(rank%(PE低), rank%(PB低), rank%(DY高))
Momentum% = rank%(60D報酬率)
Quality%  = mean(rank%(ROE高), rank%(負債比低))
```

**🤖 提示詞**
```
對前300大（排除ETF）各因子轉排名百分位，依「穩健型」權重加權計算總分，
輸出總分前10：代號/名稱/總分/價值分/動量分/品質分/成長分
```

## 八、風險管理（Risk Management）

### 三層風控

| 層級 | 機制 | 預設參數 |
|------|------|---------|
| 個股 | 停損 / 停利 | -8% 停損、+20% 停利或移動停利 |
| 個股 | 部位上限 | 單檔 ≤ 總資金 10% |
| 組合 | 產業集中度 | 單一產業 ≤ 30% |
| 組合 | 現金水位 | 空頭時保留 20~50% 現金 |
| 系統 | 大盤濾網 | 指數 < 季線時降低持股 |

### 部位大小（ATR 法）

```
單筆風險額 = 總資金 × 風險比例(建議1%)
每股風險   = 進場價 - 停損價 = k × ATR(14)   （k 常取 2）
買進股數   = 單筆風險額 / 每股風險
```

### 停損方式比較

| 方式 | 說明 | 適用 |
|------|------|------|
| 固定百分比 | 跌破成本 -8% | 新手、簡單 |
| ATR 移動 | 停損 = 最高價 - 2×ATR | 趨勢單 |
| 均線停損 | 跌破 MA20 出場 | 波段單 |
| 時間停損 | 持有 N 日未達標出場 | 事件驅動 |

**🤖 提示詞**
```
對持股清單，用 daily_prices_YYYYMMDD 算 ATR(14)，
以「單筆風險1%、停損=2×ATR、單檔上限10%」計算每檔建議股數與停損價，輸出表格
```

## 九、回測框架（Backtesting Framework）

### 回測流程

```
歷史資料(daily_prices_YYYYMMDD) → 依策略產生每日訊號 →
模擬進出場(含手續費/滑價) → 記錄每筆交易與每日淨值 → 計算績效指標
```

### 關鍵參數與假設

| 項目 | 建議設定 |
|------|---------|
| 期間 | 2024–2026（含多空段） |
| 再平衡頻率 | 每日 / 每週 / 每月 |
| 手續費 | 買賣各 0.1425%（可打折） |
| 交易稅 | 賣出 0.3% |
| 滑價 | 0.1~0.3% |
| 初始資金 | 1,000,000 |

### 避免的陷阱

| 陷阱 | 說明 | 對策 |
|------|------|------|
| 前視偏誤 | 用到未來資料 | 訊號只用當日及之前 |
| 存活者偏誤 | 忽略下市股 | 納入歷史成分股 |
| 過度擬合 | 參數硬湊 | 樣本內外分割、走動最佳化 |
| 忽略成本 | 未計費用 | 納入手續費/稅/滑價 |

**🤖 提示詞**
```
用 daily_prices_YYYYMMDD 對「策略X」回測 2024-01-01~2026-06-30，每月再平衡，
手續費0.1425%×折扣、賣出稅0.3%、滑價0.1%，輸出：總報酬/年化/最大回撤/夏普/勝率/交易次數
```

## 十、績效分析（Performance Analytics）

### 核心績效指標

| 指標 | 公式 / 定義 | 良好基準 |
|------|-----------|---------|
| 總報酬率 | (期末淨值/期初)-1 | 優於大盤 |

| 勝率 | 獲利筆數/總筆數 | > 50% |
| 盈虧比 | 平均獲利/平均虧損 | > 1.5 |
| Beta | 對大盤敏感度 | 依風格 |
| Alpha | 超額報酬 | > 0 |
