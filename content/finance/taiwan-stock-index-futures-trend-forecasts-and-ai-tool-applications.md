### 可觀察的分析維度

**技術面**（最容易讓 Agent 做）包含 K 線結構（日線/週線多空偏向）、RSI 是否超買超賣、MACD 金死叉、布林通道位置、以及 5/20/60 日均線排列。

**市場情緒面**要看三樣東西：未平倉量變化（量增價漲 vs 量縮反彈性質不同）、Put/Call Ratio（P/C > 1.5 代表市場偏悲觀）、以及外資在台指期的多空淨口數。這些資料從期交所網站或 AKShare 可以取得。

**總經/消息面**包含 Fed 利率決策日程、美股（尤其 NQ / 費城半導體）收盤表現、台積電 ADR 走勢、以及任何 AI 類股重大消息，因為現在 TWN1 和 NVDA/TSMC 高度連動。

---

### 可用的 Skills / 工具

你現在有兩個 Hermes Skills 非常適合這個任務：

**`hermes-wallstreet-agent`** — 專責情報收集和快速掃描，適合問「今日台指期異常訊號」或「外資買賣超彙整」。

**`wall-street-portfolio-manager`** — 可以做技術分析、訊號評級（S/A/B/C）、甚至生成 PDF Dashboard 報告，適合深度的多空結構分析。

另外 **Web Search** 可以搜尋即時新聞，補技術面之外的消息缺口。

---

### 關鍵限制（很重要）

Claude **無法自動抓取 TWN1 的即時報價**，因為 TWN1 是期貨合約，沒有內建的即時資料來源。解決方式有兩個：

1. **你自己貼入當日數據**（收盤價、量、日期）再讓 Agent 分析
2. **在 Hermes 系統中串接 AKShare 或 Yahoo Finance Python Skill**，讓系統自動在提示詞前先跑一段資料收集腳本

### 建議提示詞範本

**快速技術判斷（適合開盤前）：**

```
請分析 TWN1 富台指。
今日收盤：[收盤價]，日成交量：[量]
近5日收盤：[22800, 22650, 22700, 22900, 23100]

分析：RSI(14)、MACD、5/20/60MA 偏向
判斷明日偏多或偏空
給出壓力支撐區間
訊號強度評 S/A/B/C
```

**消息面整合（適合收盤後）：**

```
請搜尋今日美股收盤、Fed相關動態、外資期現貨動向、台積電ADR
整合成對明日 TWN1 走勢影響的摘要判斷
結論要有明確的多/空/觀望立場
```

**完整三層判斷（適合重要結算週）：**

```
請以三Agent模式分析明日 TWN1：
① Hermes — 收集未平倉量、P/C Ratio、外資口數
② Technical — 分析日線週線多空結構  
③ Risk — 評估本週是否有重大風險事件（Fed/財報）
輸出：方向判斷 + 信心評級（S/A/B/C）
```
