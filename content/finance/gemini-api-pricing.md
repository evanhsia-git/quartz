# Gemini API 定價摘要

> **來源**：https://ai.google.dev/gemini-api/docs/pricing（繁體中文）
> **最後更新**：2026-05-28（Google 官方）、本頁建立 2026-06-01

---

## 定價方案概覽

| 方案 | 內容 | 資料用途 |
|------|------|----------|
| **免費方案** | 免費輸入/輸出詞元、Google AI Studio | ✅ 會用於改善產品 |
| **付費方案** | 更高頻率限制、情境快取、批次 API（-50%）、最新模型 | ❌ 不會用於改善產品 |
| **Enterprise** | 大規模部署、專屬支援、進階安全、佈建輸送量、用量折扣 | ❌ 不會用於改善產品 |

**計費模式（所有付費方案適用）：**
- **標準**：一般計費
- **批次**：降低 50% 成本
- **Flex**：較低推理成本
- **優先順序**：更高服務優先順序

## 降低成本技巧

1. **批次 API**：可降低 50% 成本
2. **脈絡快取**：重複使用相同上下文可省輸入費用
3. **Flex 模式**：較低推理成本（比標準便宜約 50%）
4. **Flash-Lite**：最便宜的文字模型（$0.10/百萬詞元輸入）
5. **Imagen 4 Fast**：最便宜的圖片生成（$0.02/張）
6. **Veo 3.1 Lite**：最便宜的影片生成（$0.05/秒）

---

## 免費方案限制

- `gemini-2.0-flash` 與 `2.0-flash-lite` **已於 2026-06-01 淘汰**
- 免費方案內容會用於改善 Google 產品
- 無情境快取、無批次 API
- 頻率限制較低
