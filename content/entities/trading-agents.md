# TradingAgents

TradingAgents 是一個多智能體 (Multi-agent) LLM 金融交易框架，模擬現實中交易公司的運作模式。

## 核心功能
- **模擬運作**：模擬現實世界交易公司，多智能體協同工作。
- **智能體角色**：
    - 基本面分析師
    - 情緒分析專家
    - 技術分析師
    - 交易員
    - 風險管理團隊
- **協作機制**：智能體間進行動態討論，協同評估市場狀況並制定最優交易策略。
