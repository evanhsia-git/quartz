# FinLab

FinLab 是一個由量化交易與資料工程背景專業團隊組成的金融科技服務平台。

## 概述
- **成立時間**：2018 年起持續維護
- **核心業務**：提供台股、美股、韓股、日股、港股的 Python 量化交易與回測平台。
- **目標客群**：量化交易員、資料科學家、程式交易開發者。
