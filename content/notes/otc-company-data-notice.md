# 上櫃板公司資訊使用說明

## 使用建議與注意事項

如何使用這些CSV檔：
- 點擊上方連結後，CSV檔案會直接下載或在新分頁中顯示純文字資料。
- 你可以用 Excel 直接開啟（注意：中文可能需用「資料→從文字檔/CSV匯入」並選擇 UTF-8 編碼）。
- 或使用 Python (pandas)、R 等程式語言進行資料分析。

## 資料編碼問題
- 部分檔案因系統使用 BIG5 編碼，可能在 Excel 中開啟會出現亂碼（例如「啓」變成「?」）。
- 解法：不要直接用 Excel 點開，而是開啟空白 Excel → 使用「資料」→「從文字檔/CSV 匯入」，並選擇「檔案原始編碼：65001: Unicode (UTF-8)」即可正常顯示。

## 資料涵蓋範圍
- 上市公司、上櫃公司、興櫃公司的 CSV 資料集通常包含完整的公司基本資料（公司代號、名稱、地址、董事長、實收資本額、發行股數等）。
