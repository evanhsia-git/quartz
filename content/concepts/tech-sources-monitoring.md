# Tech Sources Monitoring (科技媒體監測導航)

本頁面用於監測您指定的科技新聞源，並作為自動化任務的資訊導航中心。

## 監測站點分類

### ⚡️ 快訊與綜合門戶
- [IT之家](https://www.ithome.com)：側重消費數碼、軟件與互聯網。
- [TechWeb](https://www.techweb.com.cn)：覆蓋 IT 業界、通信與產業動向。
- [新浪科技](https://tech.sina.com.cn)：24小時滾動報道。

### 📈 創業與商業視角
- [36氪](https://36kr.com)：創業投資風向標，深度產業分析。
- [虎嗅網](https://www.huxiu.com)：科技與商業的深度解讀。
- [鈦媒體](https://www.tmtpost.com)：科技、金融與產業融合分析。

### 🎯 垂直與特色領域
- [愛範兒](https://www.ifanr.com)：消費電子、智能汽車評測。
- [賽迪網](https://www.ccidnet.com)：工信部研究院背景，政策與硬科技。
- [極客公園](https://www.geekpark.net)：技術創新與產品變革。
- [機器之心](https://www.jiqizhixin.com)：AI 大模型與前沿科技研發。
